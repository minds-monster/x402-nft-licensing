# x402-nft-licensing [DEPRECATED]

> **Status**: Deprecated in favor of the unified minds.MONSTER payments model.

This repository contains the initial experimental implementation of the x402 rewards model when it was referred to as "licensing" rather than "payments".

## Original Purpose
Developed to prototype token-gated asset routing and split licensing rewards (distributing payouts to creators and owners) before the architecture was centralized under the main Minds payment service.
